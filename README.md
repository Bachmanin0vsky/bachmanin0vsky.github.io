# Yonghan Jiao Engineering Portfolio

[Visit the portfolio](https://bachmanin0vsky.github.io/)

The portfolio includes six engineering case studies and a downloadable one-page résumé. It is a static website with HTML, CSS, and assets.

## Publish with GitHub Pages

1. Upload the contents of the ZIP to the root of `main` in `bachmanin0vsky.github.io`. Keep `assets/` and `projects/` as folders beside `index.html`.
2. In **Settings → Pages**, choose **Deploy from a branch**, then **main** and **/(root)**. Save the settings.
3. After the deployment succeeds, use **Visit site** to open the portfolio.

The empty `.nojekyll` file tells GitHub Pages to serve the static files directly.
