# Yonghan Jiao — engineering portfolio demo

This is a single-file static website for the 24-696 portfolio initial draft. Open `index.html` in a browser to preview it. The navigation links point to working sections of the same page.

## Publish with GitHub Pages

1. Sign in to GitHub. Create a **public** repository named `YOUR-USERNAME.github.io` (substitute your actual username). With a free GitHub account, use a public repository for GitHub Pages.
2. In the repository, choose **Add file → Upload files**. Upload `index.html` and optionally `README.md`. Keep `index.html` in the repository root. Commit the files to the `main` branch.
3. Open **Settings → Pages**. Under **Build and deployment**, set **Source** to **Deploy from a branch**, **Branch** to `main`, and folder to `/(root)`; click **Save**.
4. Open `https://YOUR-USERNAME.github.io/` or use **Settings → Pages → Visit site**. Publishing can take up to 10 minutes.
5. Submit the live URL for the initial-draft assignment. Check all three navigation links on desktop and phone.

For a repository called `portfolio` instead, the site URL is `https://YOUR-USERNAME.github.io/portfolio/`; the same site works because its section links are relative.

## Finish before the final submission

- Replace the resume placeholder with your reviewed, one-page resume PDF. Upload `resume.pdf` in the repository root, then link to it from the Resume section with `<a href="resume.pdf">Download resume (PDF)</a>`.
- Add project figures with captions, evidence for results, and detailed descriptions of your own role and the work's wider value.
- Review every claim, dates, contact information, privacy, and the AI disclosure. Prepare the separate one-page justification memo required for the final portfolio.
